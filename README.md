# Codex 儲存庫

此處是 Codex 儲存庫，用於集中管理使用 Codex 製作的專案、程式與成果檔案。各專案以獨立資料夾整理，並依檔案用途分類。

## 專案

- [SRT 白板動畫](srt-whiteboard-animation/)：依繁體中文字幕製作的智慧型手機選購白板動畫，包含影片、字幕、預覽圖與製作程式。
